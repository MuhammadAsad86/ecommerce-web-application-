# 🛒 RA Collection | MERN E-Commerce Web Application

A complete full stack e-commerce platform built using the MERN stack.  
The application includes a modern customer shopping website, secure backend APIs, and a powerful admin dashboard for managing products and orders.

The project focuses on real-world e-commerce functionality including authentication, product management, cart system, order processing, payment integration, and cloud image storage.

# 📌 Features

## 👤 Customer Features

✅ User registration and login  
✅ Browse products by category  
✅ Product details page  
✅ Search products  
✅ Add products to cart  
✅ Update cart quantity  
✅ Remove cart items  
✅ Select product sizes  
✅ Place orders  
✅ View order history  
✅ Order status tracking  
✅ Secure checkout system

✅ Admin dashboard
