# 🛒 RA Collection | MERN E-Commerce Web Application

A complete full-stack e-commerce platform built using the MERN stack. The application includes a modern customer shopping website, secure backend APIs, and a powerful admin dashboard for managing products and orders.

The project focuses on real-world e-commerce functionality including authentication, product management, cart system, order processing, payment integration, and cloud image storage.

## 🚀 Live Demo

- **Customer Website:** [https://ecommerce-web-application-dusky.vercel.app/](https://ecommerce-web-application-dusky.vercel.app/)
- **Admin Panel:** [https://ecommerce-web-application-ae4d.vercel.app/](https://ecommerce-web-application-ae4d.vercel.app/)

## 📌 Features

### 👤 Customer Features
- User registration and login
- Browse products by category
- Product details page
- Search products
- Add products to cart
- Update cart quantity
- Remove cart items
- Select product sizes
- Place orders
- View order history
- Order status tracking
- Secure checkout system

### 🛠 Admin Panel Features
- Admin authentication
- Admin dashboard
- Add new products
- Upload multiple product images
- Manage product listings
- Remove products
- View customer orders
- Update order status

Order status options:
- Order Placed
- Packing
- Shipped
- Out for Delivery
- Delivered

### 💳 Payment Integration
Integrated payment gateway:
- Stripe Payment Gateway

Features:
- Online payment processing
- Payment verification
- Secure order creation

## 🧰 Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Payment:** Stripe API
- **Image Storage:** Cloud-based image hosting
- **Deployment:** Vercel

## Getting Started

```bash
git clone https://github.com/MuhammadAsad86/ecommerce-web-application-.git
cd ecommerce-web-application-
npm install
npm start
```

Set up your `.env` file with MongoDB URI, JWT secret, and Stripe API keys before running the backend.
